TA THE FASHION BOUTIQUE — STYLE GALLERY

IMAGE FOLDER
All gallery photos are stored in one folder named exactly: Images

IMAGE FILE NAMES
Use three-digit numbering from STYLE001 to STYLE120.
Examples:
  Images/STYLE001.jpg
  Images/STYLE002.jpg
  ...
  Images/STYLE120.jpg

JPG and PNG are supported. The gallery tries JPG first and then PNG for each
style number. Keep the Images folder beside index.html, script.js, and style.css.
File names must match exactly, including uppercase STYLE and the three digits.

STYLE GALLERY SERIES
- Bridal Elegance: STYLE001–STYLE020
- Designer Blouses: STYLE021–STYLE040
- Festive Suits: STYLE041–STYLE060
- Lehenga Looks: STYLE061–STYLE080
- Custom Fitting: STYLE081–STYLE100
- Kids Collection: STYLE101–STYLE120

The gallery displays the images in numeric order under the corresponding
collection. Three existing PNG files (STYLE001.png, STYLE002.png, STYLE003.png)
have been placed in Images. Add your remaining photos using the naming pattern.

HOW TO PUBLISH
Upload index.html, style.css, script.js, and the entire Images folder together
to your website hosting provider. Do not upload only the HTML file.
