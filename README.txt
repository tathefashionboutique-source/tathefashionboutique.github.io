# TA THE FASHION BOUTIQUE Website

## Files
- index.html — complete website
- style.css — design and responsive layout
- script.js — mobile menu + year

## IMPORTANT: Replace these placeholders before publishing
1. WhatsApp number: search for `918178486174` in index.html and replace with the boutique's WhatsApp number including country code, without + or spaces.
2. Instagram: replace the Instagram URL with the boutique's actual Instagram profile.
3. Location: update the Sector 1 address and Google Maps search link with the exact boutique address.
4. Gallery: replace the sample Unsplash image URLs in style.css with your own boutique photos for stronger branding.

## Free hosting
GitHub Pages:
1. Create/login to GitHub.
2. Create a PUBLIC repository named `YOURUSERNAME.github.io`.
3. Upload index.html, style.css and script.js.
4. Repository Settings -> Pages -> Deploy from branch -> main -> / (root) -> Save.
5. Your site will be available at `https://YOURUSERNAME.github.io/`.

You can later connect a custom domain such as `www.yourboutique.com`.
