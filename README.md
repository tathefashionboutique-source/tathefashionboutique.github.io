## Style Gallery image folders
Gallery images are stored under `Images/` in six category folders:
- `Bridal Elegance` — `STYLE01` to `STYLE20`
- `Designer Blouses` — `STYLE21` to `STYLE40`
- `Festive Suits` — `STYLE41` to `STYLE60`
- `Lehenga Looks` — `STYLE61` to `STYLE80`
- `Custom Fitting` — `STYLE81` to `STYLE100`
- `Kids Collection` — `STYLE101` to `STYLE120`

Save each image as `.jpg` or `.png` using its matching style number. Example: `Images/Bridal Elegance/STYLE001.jpg` or `Images/Bridal Elegance/STYLE01.png`. The gallery checks JPG first and then PNG. For a JPG image, use the `.jpg` extension (not `.jpeg`).
