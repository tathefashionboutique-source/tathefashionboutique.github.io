2. Upload/commit index.html, script.js, style.css, sitemap.xml and the other files to the root of the existing GitHub repository:
   https://github.com/tathefashionboutique-source/tathefashionboutique.github.io
3. Keep the current GitHub Pages publishing configuration.

5. Open this sitemap URL:
   https://tathefashionboutique-source.github.io/tathefashionboutique.github.io/sitemap.xml
6. In Google Search Console, add/verify the URL-prefix property:
   https://tathefashionboutique-source.github.io/tathefashionboutique.github.io/
7. In Search Console > Sitemaps, submit:
   sitemap.xml
8. Use URL Inspection for the canonical homepage URL and request indexing.

ROBOTS.TXT NOTE
This is a GitHub Pages project site under a shared github.io host. A robots.txt placed inside this project folder is served at /tathefashionboutique.github.io/robots.txt, but search engines normally look for robots.txt at the host root (/robots.txt). Do not assume a project-folder robots.txt controls crawling. No robots.txt is needed for this basic setup because the site does not intentionally block crawling.
